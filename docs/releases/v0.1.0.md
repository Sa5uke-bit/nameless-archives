《无名档案》首个公开体验版，包含五章侦探故事与多分支结局。

## 下载与开始

1. 在下方 Assets 下载 **nameless-archives-v0.1.0-windows-x86_64.zip**。
2. 完整解压 ZIP，双击 **无名档案.exe**。
3. 选择“新调查 · 第一章”，开始调查。

**无需安装 Godot，无需 clone 仓库，游戏可离线运行。** GitHub 自动生成的 Source code 文件是源码，不是可直接玩的游戏包。

## 内容与操作

包含五章完整流程、调查笔记、证据推理、磁带试听、时间线校准、地址图层与材料索引，以及三个独立存档位。

- 鼠标左键：移动、调查、推进对白；右键取消自动移动。
- A / D 或方向键：移动；E / 空格：调查和推进对白。
- Tab：调查笔记；Esc：暂停、设置、保存和读取。
- 后续章节随通关解锁。现有 Windows 旧版存档继续兼容。

## 当前状态

这是 **Windows 64 位公开体验版**。谜题提示、动画和语音仍在打磨；AI 配音尚未逐条完成人耳听测，尚未完成全面硬件兼容性测试。暂不提供 macOS / Linux 构建。

游戏采用 Godot 4.6.2，使用生成美术和 AI 合成对白。随包附操作说明、第三方素材登记及引擎许可证。`SHA256SUMS.txt` 用于校验下载文件。
