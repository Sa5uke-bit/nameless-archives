《无名档案》｜Nameless Archives
v0.1.0 — 首个公开体验版（Windows 64 位）

开始游戏
1. 把 ZIP 完整解压到一个文件夹。
2. 双击“无名档案.exe”。无需安装 Godot，也不需要 clone 源码。
3. 点击“新调查 · 第一章”，选择空存档位开始。
游戏本身无需联网，后续章节随通关依次解锁。

操作
鼠标左键：移动、靠近调查、推进对白。
鼠标右键：取消自动移动。
A / D 或方向键：左右移动。
E / 空格：调查、推进对白。
Tab：调查笔记。
Esc：暂停、设置、保存与读取。
共有三个独立存档位；音量、显示和按键可在设置中调整。

版本说明
包含五章故事、多分支结局、调查推理、章节专属谜题和 AI 合成对白。
这是公开体验版，谜题提示、动画、语音读音和表演还会继续完善。
目前尚未逐条完成人耳听测，也未完成全面硬件兼容性测试。
当前提供 Windows 64 位版本，暂不提供 macOS / Linux 构建。

存档
Windows 继续使用旧项目的用户数据目录：
%APPDATA%/Godot/app_userdata/不存在的住客/
更新游戏时可保留这个目录；解压新版不会主动删除旧存档。
