# 《谢幕之后》灰盒实机测试指南

> 版本：v0.1
> 日期：2026-09-04
> 目的：验证玩家是否能在系统揭晓前，用游戏内材料自行提出三个核心结论

## 测试原则

- 测试者此前不知道第二章答案；开发者不解释角色关系、磁带原理或正确结论。
- 从标题画面的“第二章·谢幕之后（灰盒）”开始，允许测试者自由调查。
- 只有当测试者明确认为系统失灵或连续卡住五分钟时才提供操作提示；提示内容与次数都要记录。
- 不以“最终选对了”为唯一通过标准。逐项尝试也可能通关，必须记录玩家第一次自然形成正确假设的时刻和依据。
- 测试完成前不展示 `CHAPTER_02.md`、纸面测试包或本指南后面的判断标准。

## 测后提问

1. 在游戏正式确认前，你分别在什么时候猜到谢幕者、录音来源和胸针去向？
2. 哪项结论最确信，哪项更像排除法或猜测？
3. 哪条信息最有用？哪条看起来重要却没有发挥作用？
4. A/B 磁带比对是在推理，还是只是在找相同文字？
5. 最终公开选择是否让你感到两边都有代价？
6. 如果只改一个地方，你希望改什么？

## 当前通过标准

至少两名不知情测试者完成全章，并满足：

- 至少一人在 D21 提交前明确说出“照片只证明造型在场，不能证明是程书瑜”；
- 两人都能在 D22 揭晓前指出 A 带不是谢幕时的连续原录音，且不需要专业音频知识；
- 两人都能重建“胸针谢幕时仍在—方芸归还—梁再次开柜—梁典当”的主路径；
- 没有必要线索因热点、对白条件或界面反馈而稳定遗漏；
- 即使选择不同结局，两人都能说明保护隐私与公开追责之间的代价。

若玩家只靠逐项点击或错误答案反馈通关，则记为流程可完成，但谜题验证未通过。应先修订线索与反馈，再考虑正式美术、配音或录音制作。

## 已知非测试目标

当前灰盒的程序绘制场景、人物剪影、文字录音和复用环境声都不是最终品质评审对象。本轮不评价画风统一度、表演质量或磁带音色；但如果占位表达妨碍理解，仍需记录为可用性问题。
