# 《谢幕之后》纸面盲测主持指南

> 文档版本：v0.1
> 更新日期：2026-09-04
> 对应材料：[`CHAPTER_02_PAPER_PACKET.md`](CHAPTER_02_PAPER_PACKET.md)
> 注意：本文件包含完整答案，不交给测试者

## 1. 测试目标

本轮不是测试文字是否好看，而是验证四件事：

1. 玩家能否从视觉材料提出“照片只证明造型，不证明演员本人”；
2. 玩家能否不依赖专业声学知识，判断 A 带是后来整理的副本；
3. 玩家能否重建 P-17 的完整保管路径，而不是因为典当存根直接跳过前面证据；
4. 玩家是否理解公开程书瑜的临时身份不是恢复方芸清白的必要条件。

主持人不能解释材料、纠正推理或暗示需要使用哪一条线索。测试者提问时，只能重述已经发出的文字，或者记录“游戏需要补充这一信息”。

## 2. 测试流程

建议总时长 35～50 分钟：

1. 阅读测试者须知：2 分钟；
2. 材料包 A：8～12 分钟；
3. 材料包 B：10～15 分钟；
4. 材料包 C：10～15 分钟；
5. 最终选择与访谈：5～8 分钟。

每包发出前记录时间。测试者交回答案后再发下一包，不允许回改早先答案，但允许在新材料旁记录“我改变了判断”。

## 3. 预期推理与可接受变体

### 材料包 A

最低通过结论：

> F24 只能证明女主角造型在台上；备用衣被从短档放长并放松腰封，照片中的方扣修补鞋属于杨佩，因此杨佩最可能替位。

可接受：测试者暂时认为方芸知道逃离计划，只要能区分“知道替位”和“知道永久离开”仍需更多证据。

不应接受为完整答案：

- 只因“杨佩是替补”就认定她上台；
- 只凭鞋码认定身份；
- 引入双胞胎、易容或第二名未列出的演员。

若半数测试者仍认为程书瑜可以穿 38 码鞋完成谢幕，应强化圆扣鞋上的终场颜料、方扣鞋上的面具亮粉与 C-02 尺寸档位的交叉关系，而不是添加人物自白。

### 材料包 B

最低通过结论：

> B 带连续记录了排练台词、轻咳、双铃和随后的雨声器测试；A 带复制了其中一段并接在掌声后。A 带盘芯次日才领出，也不可能是当晚原带。

测试者不必知道磁带剪接、频谱或具体设备型号。“内容组合相同＋来源时间晚于演出”已经足够。

可接受：测试者认为徐峥明知造假。其主观知情程度要到人物询问阶段处理，不影响录音来源结论。

不应接受为完整答案：

- 仅凭底噪变化宣布录音伪造；
- 认为 B 带从 A 带复制，因为 B 带连续后文和领料标签已经提供相反来源；
- 把 A 带当作现代数字合成。

### 材料包 C

最低通过路径：

```text
21:18  程书瑜离开
  ↓
21:27  P-17 仍在谢幕者身上
  ↓
21:38  方芸的 0387 副联记录归还
  ↓
21:40  方芸交回钥匙
  ↓
22:05  梁绍康独自开柜
  ↓
09/21  梁以本人姓名典当同编号、同修痕胸针
```

典当存根能证明梁最终持有胸针，但不能独自证明他从柜中取走。照片、副联、钥匙记录和典当特征共同排除“程书瑜带走”及“方芸归还后又取走”。

可接受：测试者对副联是否绝对真实保持怀疑，只要认识到编号、装订齿、物品特征和后续钥匙路径使它具有较高可信度。

## 4. 舞台动线草图

以下只用于验证 1999 年时间线，不直接交给第一轮测试者。单位为设计距离，不代表最终 Godot 像素比例。

```text
                           北 / 后台

          ┌──────────────货运门──────────────┐
          │                 │                 │
          │  化妆间         │  服装库         │
          │  [C-01鞋]       │  [C-02/P-17]    │
          │      └──8 m──┐  │                 │
          │              │  │                 │
          │          左侧台 ├──10 m──音控间   │
          │              │  │      [A/B带]    │
          └──────12 m────┴──┴─────────────────┘
                         │
                    主舞台 14 m
                         │
                      观众席
```

设计时间核对：

- 程书瑜 21:12 从主舞台左侧退场，约 8 m 到化妆间；
- 更换预先准备的便服按 3～4 分钟估计；
- 化妆间至货运门约 12 m，正常步行不足 20 秒；
- 因此 21:18 离开货运门有约 1～2 分钟余量；
- 杨佩原本位于左侧台，21:21 取得刚调到长档并放松腰封的 C-02，6 分钟足以换装并走到主舞台候场点；
- 最终灰盒必须实测路线与换装叙事时间；如果玩家可见地图明显更小或更大，应调整时间而不是让角色瞬移。

## 5. A 带制作流程的设计约束

纸面谜题只要求玩家证明 A 带不是原始记录，不要求玩家还原每根线缆。制作前仍须选定一种具体、可在 1999 年成立的设备流程：

```text
谢幕掌声来源带 ─┐
                 ├─ 调音台/线路输入 ─ 录音卡座 ─ A 带
B 带台词片段 ───┘
```

正式实现前需补一份具体设备或同时代说明书，确认：

- 两个播放源可以先后接入同一录音卡座；
- 操作不依赖电脑剪辑；
- A 带留下的声场切换与电机声符合设定；
- 玩家无需理解线路知识也能从内容来源完成推理。

如果找不到合适设备依据，应把 A 带改成明显的“整理带”，并把谜题重心完全放在旧调查错误地把整理顺序当成时间顺序，不可用虚构设备能力兜底。

## 7. 通过门槛

至少两名不知情测试者完成全部材料后，同时满足以下条件，才把章节状态改为“纸面谜题通过”：

- 两人都能在 A 包指出照片不能确认本人；
- 两人中至少一人无需提示锁定杨佩，另一人最多接受一次非答案式提示；
- 两人都能在 B 包确认台词早已存在，且 A 带不是当晚原带；
- 两人都能在 C 包排除程书瑜带走 P-17；
- 两人中至少一人主动区分“恢复方芸清白”与“公开程书瑜去向”；
- 没有任何必要结论只能通过主持人口头补充才能成立。

若未通过，先删改或替换问题线索，再进行新一轮不知情测试；不要让同一测试者反复测试同一答案并计作独立通过。
