# 第四章实机试玩记录：《被删去的地址》

本表用于记录自然试玩反馈，不把自动通关等同于谜题难度已经过外部验证。第一遍请勿提前阅读 `CHAPTER_04.md` 的客观真相。

## 开始方式

- 从标题界面选择“第四章 · 被删去的地址”；
- 可保留第三章实际结局，观察开场信任措辞是否自然；
- 鼠标或键盘均可完整操作，地图叠合时按材料形成顺序点击图层。

## 重点观察

1. 玩家何时区分“没有独立产权”和“没有实际生活地址”；
2. 玩家是否意识到地图、底册和户籍索引共享同一修订来源；
3. 叠图界面的固定锚点提示是否足以理解，而不直接泄露顺序；
4. 玩家能否在终幕前指出裁切发生在拍摄与完整归档之后；
5. 玩家是否把火灾责任落实到断电、封门、补偿和裁切动作，而非笼统归因于档案错误；
6. 《门牌》与《底图》的代价是否清楚，选择是否来自记录边界而非善恶猜测。
