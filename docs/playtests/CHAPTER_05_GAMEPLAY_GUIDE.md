# 第五章实机试玩记录：《共同的名字》

本表用于记录自然试玩反馈。自动通关可以证明流程和状态成立，不能证明玩家会以预期节奏理解共享委托或接受最终选择。

## 开始方式

- 完整体验建议沿用前四章真实结局后进入第五章；
- 单章测试可从标题选择“第五章 · 共同的名字”，此时使用《姓名》《清白》《校正》《门牌》的标准前情；
- 材料索引中，每项材料只能进入“可公开事实、需保护身份、来源不足、可封存验证”之一。

## 重点观察

1. 玩家在 D51 前是否已经猜到共同记号来自多人，以及答案是否仍有“意义上的回收感”；
2. 玩家能否区分“多人使用信箱”“多人写信”和“存在组织”三种不同结论；
3. 二十分钟路戳与九十分钟路线下限是否足以排除单人投递；
4. 玩家是否理解删节报告没有改写结论，但缺少逐项同意；
5. 材料分类的四个类别是否清楚，错误反馈能否指出具体冲突；
6. 《索引》可用或锁定原因是否被看见，不会被误解成隐藏道德评分；
7. 三个结局是否都有可感知代价，《索引》是否仍显得过于完美；
8. 顾宁的承认是否被误解成定案所需证据或幕后首领揭晓。
