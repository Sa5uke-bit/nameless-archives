# 第五章设计文档：《共同的名字》

> 状态：制作设计定稿
> 时间与地点：2008 年，澄湾七码头停用邮政代办所及侦探的临时归档室

## 1. 章节定位

第五章不是再增加一名更大的幕后罪犯，而是回收前四章共同出现的匿名委托、删节报告和玩家的公开选择。表层问题是“谁一直在安排案件”，客观答案是：固定记号与句式属于一项共享署名，不同求助者只接触过其中一段转交链。

本章的惊喜来自意义变化，而不是身份保密。敏锐玩家在第三章已经可以猜到委托人不止一人；第五章要让玩家亲手证明这一点，并决定自己的五章档案如何成为一份既能复核、又不把人当作证据附件的公共记录。

## 2. 回归人物与边界

- **顾宁**：提出最早的共同记号，用它转交第一把钥匙；她不是后续案件的组织者，也不知道各案答案。
- **方芸**：第二章求助者。她把剧场节目单纸裁成信封内衬，并保留了自己的折法；她要求洗清罪名，不同意公开程书瑜去向。
- **罗遥**：第三章票务员同事。她从邮袋里分出待转交的信，记录过交接时刻；她知道路线，不知道第一章匿名者身份。
- **蒋禾**：第四章求助者。她比较过删节报告，指出“保护身份”和“替别人决定”之间的边界。
- **温岑**：旧邮路的最后一名保管者。只负责钥匙轮换和停用信箱，不掌握所有寄信人名单。

人物回归必须承担证据来源或价值冲突，不能只是终章点名。共同署名不是组织名称，不建立首领、成员等级、秘密资金或全城网络。

## 3. 客观真相

第一章后，顾宁在钥匙信末画了一个不完整的方框，意思是“记录仍有缺口”。温岑认出这个记号适合做不暴露姓名的转交标识。后来方芸、罗遥和蒋禾分别通过自己已有的关系接触这条路线；她们沿用一句格式化请求，却使用自己的纸张、笔迹、折法与知识。

没有任何一人能写出全部委托：

- 第一章钥匙信知道 307 和顾海川，却不知道剧场 A/B 带；
- 第二章信使用节目单纸，只知道公开报道中的林小满结果；
- 第三章信随客运邮袋到达，误把第二章未公开的磁带编号写成报道编号；
- 第四章信知道前三章删节结论，却不知道被封存的现址与真实姓名；
- 钥匙交接记录显示部分信件在同一天由相距较远的两条路线投入，不可能由一人连续完成。

删节报告也不是为了操纵侦探。不同保管者尝试把“可用于证明责任的事实”与“会暴露求助者的身份”分开，却没有统一取得当事人同意。终局需要纠正的正是这套有善意但不完整的记录方式。

## 4. 四段流程与证据

### 4.1 临时归档室：比较四封信

- `E501` 第一章钥匙信原件：顾宁笔迹，普通账簿纸，记号是后补的一笔；
- `E502` 第二章节目单内衬：纸张纤维与剧场旧节目单吻合，折线不同；
- `E503` 第三章邮袋转交件：机械路戳和雨渍位置证明它走客运邮路；
- `E504` 第四章报告复写件：正文由温岑誊写，姓名删节由蒋禾另笔标注。

推理 `D51`：相同记号只能证明共同格式，纸张、笔迹、折法和形成顺序证明四封信不是同一人伪装书写。

### 4.2 七码头代办所：重建保管路线

- `E505` 停用信箱租用卡：登记的是“七码头互助阅报组”这一公开柜位用途，不对应单个自然人；
- `E506` 钥匙轮换簿：四个不重叠的保管时段，只记交接凭证，不记真实姓名；
- `E507` 两条投递时刻：同日相隔二十分钟出现两封信，路线耗时至少九十分钟；
- `E508` 知识边界批注：各信对前案只知道公开层或自己经手层，错误也不相同。

推理 `D52`：这是一条多人接力的有限保管路线，不存在掌握全部案件的单一委托人。

### 4.3 共同记录室：审查删节方法

- `E509` 责任索引页：删节本始终保留证据编号和可复核出处，没有改写定案结论；
- `E510` 四份同意便笺：不同当事人对实名、现址和原件公开有明确且互相不同的选择；
- `E511` “幕后首领”传闻页：只有转述，没有原件、日期和独立来源；
- `E512` 封存原件登记：原始信件可由第三方核验，但不必随公开报告复制姓名。

推理 `D53`：删节本的目的主要是保护求助路径，但未经同意的删节同样可能抹掉当事人的主动表达；最终档案必须按来源和用途分类，而不是统一公开或统一销毁。

### 4.4 最终记录台：材料分类

玩家完成一张八项材料索引，每项只能进入一个类别：

| 材料 | 正确类别 | 理由 |
| --- | --- | --- |
| 五章已验证的责任结论与证据编号 | 可公开事实 | 能独立复核，且是追责所必需 |
| 各章责任人的签字、工单与修改动作 | 可公开事实 | 指控对象与行为明确 |
| 求助者现住址与未使用的真实姓名 | 需保护身份 | 不是证明责任所必需 |
| 医疗、亲属和逃离后的私人细节 | 需保护身份 | 只保留当事人同意的必要部分 |
| “所有案件由同一首领安排”的传闻 | 来源不足 | 无原件、日期或独立来源 |
| 未核实的共同署名使用者名单 | 来源不足 | 名单来源单一，且可能把转交者当作者 |
| 四封匿名信和删节报告原件 | 可封存验证 | 可供独立复核，不随公开副本传播 |
| 同意便笺、证据—来源对应表 | 可封存验证 | 用于审计公开边界与后续更正 |

分类错误必须提示具体冲突，例如“可验证不等于必须公开原件”“保护身份不等于销毁来源”。完成后获得 `E513`“最终记录索引”。

## 5. 终幕陈述

四问确认：

1. 相同记号为什么不能证明同一作者；
2. 什么证据排除了单一保管者连续投递；
3. 删节报告保留了什么、又缺少了什么；
4. 最后一份记录如何同时支持追责、复核与身份保护。

顾宁只在证据已经成立后确认自己提出过最初记号。她的承认不是共享委托结论所必需的线索。

## 6. 三个终局

### 《沉默》 (`silence`)

只公开去身份化的五章概要，封存全部原件和来源关系。求助者安全边界最大，但部分具体责任因缺少公开证据路径而推进缓慢。保存 `chapter_05_disclosure = protection`。

### 《全卷》 (`full_archive`)

公开完整信件、姓名、现址与来源表，迅速形成外部压力。责任链最醒目，但依赖匿名继续生活的人被重新暴露，且未经核实的关联容易被公众当成事实。保存 `chapter_05_disclosure = public`。

### 《索引》 (`index`)

公开已验证事实、责任动作与证据编号，把匿名信原件、私人身份和同意记录交由独立渠道封存核验。它推进更慢，也不能挽回已过时效或缺失原件的全部责任，但允许当事人以后更正自己的公开边界。

《索引》不是隐藏善恶值奖励。界面明确显示条件：前四章至少三次选择了分层/保护方式，且本章完成三项来源推理和材料分类。直接从章节选择启动第五章用于开发或单章体验时，采用前三章《姓名》《清白》《校正》和第四章《门牌》的标准前情；正常完整游玩则读取玩家实际结局。

保存：

- `chapter_05_disclosure = indexed`
- `chapter_05_source_complete = true`
- `chapter_05_consent = true`

若条件不足，玩家仍能看见《索引》选项及缺失原因，但只能选择《沉默》或《全卷》。

## 7. 公平性与制作边界

- D51 同时使用笔迹、纸张、折线和来源时间，不把“字不同”单独当作多人结论；
- D52 用明确的路线最短耗时排除单人连续投递，但不据此猜测具体人数；
- D53 区分“删节没有改结论”和“删节一定得到同意”，不把善意等同于合法或正确；
- 所有跨章物证都来自玩家已经见过的工具与记录类型，终章不新增能推翻前案的秘密原件；
- 三个结局都承认相同客观真相，只改变最后档案的公开范围与可复核方式；
- 不承诺具体司法结果，只呈现材料能推动和不能推动的后果。
