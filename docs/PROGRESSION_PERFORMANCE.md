# 章节顺序与人物表现迭代（2026-09-05）

## 章节规则

- 第一章始终开放。第二至第五章要求所有此前章节均有结局档案。
- 标题页禁用未解锁按钮并显示“未解锁”；实际启动入口再次校验，拒绝跳章时不重置当前案件。
- 进入后续章节/重玩保留当前档位的通关档案；“新调查”会在玩家选择并确认的档位建立独立新进度。2026-09-05 的三槽存档迭代详见 `SAVE_SYSTEM.md`。
- 为兼容旧版，已有跳章存档可以继续；未完成的前章不会被补为“已通关”。新选择章节仍执行顺序限制。
- 跨章结果现在随各个档位分别保存；同档位内使用该路线最近保存的结局，其他档位不会改变。

## 表现实现

`conversation_actor.gd` 由 HUD 在当前地点内自动接入已登记的人物透明立绘，覆盖调查场景、静态终幕和主角站姿。通过素材角色 ID 对应对白姓名，不把旁白或画外音误套给在场人物。

每个人有不同相位的轻呼吸。当前说话者增加平滑进入/退出的轻微倾斜与起伏；有配音时跟随语音播放状态结束，纯文字对白持续到换句。脚底使用原画 alpha 边界固定，左右镜像保留，不移动人物碰撞体或交互热点。它属于立绘程序表演，并非口型同步或分肢动作。

主角沿用原四帧。校正各格的身体中心和脚底注册点，按实际水平位移调整播放速度，撞墙不原地踏步；约 100 毫秒混合处理站姿/行走起停。保留步态播放位置，避免每次短移都从同一迈腿姿势硬重启。

八帧生成候选因高抬腿、重复步态或背景不透明未通过验收，没有复制进项目，也没有增加新素材依赖。本轮不宣称已完成八帧动画。后续优先做双腿交替、手臂反摆、衣摆跟随和稳定落脚的分肢动画或人工验收帧表。

## 验证

- 本机 Godot 4.6.2 编辑器导入和脚本检查。
- 五章自动通关回归全部通过，包括移动、调查、推理、结局和存档。
- 新增 `progression_performance_test.tscn`：新档锁章、启动入口拒绝且不破坏状态、缺章档案、逐章解锁、重玩保留结果、对白姓名映射、脚底固定、旁白收回动作、停止位移后回站姿。
- `performance_visual_capture.tscn` 在图形渲染器下捕获锁章标题、对话画面及四个步态，输出到 `.godot/qa/performance/`。这些截图验证布局与姿态，不能替代完整人工动态试玩。
- 自动通关测试退出时仍可能报告 Ogg 环境声播放资源未释放；详细日志定位到海浪/雨声音频播放对象。断言通过，图形捕获正常退出；该退出清理问题留待音频生命周期专项修复。
